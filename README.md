## Floor Plan Viewer

A browser-based viewer I built to display my floor plans interactively. Open `index.html` via a local server (PDF.js needs HTTP):

```bash
python -m http.server 8080
# then open http://localhost:8080
```

**Controls:**
- Drag to pan, scroll to zoom, double-click to zoom 2x
- Press `1`/`2` to switch floors
- Toolbar buttons for zoom, fit, and fullscreen
